# Klímatisztítás Budapest

Prémium klímatisztítás Budapest területén. Professzionális klímaberendezés tisztítás, karbantartás és fertőtlenítés.

## Tech Stack

- ⚡ **Vite** – ultragyors build tool
- ⚛️ **React 19** – komponens-alapú UI
- 🎨 **TailwindCSS v3** – utility-first CSS
- 🎬 **Framer Motion** – smooth animációk
- 🔗 **React Router** – SPA routing
- 🚀 **Vercel** – hosting & deploy
- 📊 **Vercel Analytics** – látogatói statisztikák

## Fejlesztés

```bash
npm install
npm run dev
```

## Deploy

A projekt Vercel-en fut. Minden `main` ágra pusholt változás automatikusan deploy-olódik.
A `dev` ág preview deploy-t kap.

## Ágak

- `main` – produkciós ág (live oldal)
- `dev` – fejlesztési ág (preview deploy)
